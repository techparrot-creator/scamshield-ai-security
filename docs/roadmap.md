# Hackathon roadmap

## Already in v1.0
- LangGraph conditional workflow
- Urdu / Roman Urdu / English
- text, URL, screenshot, and voice-note evidence
- ChromaDB + Hugging Face semantic retrieval
- BM25 keyword retrieval
- MMR, RRF fusion, score threshold, metadata boosts
- conditional multi-query expansion
- parent-context retrieval
- explainable risk score
- personalized recovery based on user exposure
- privacy-redacted case report
- Gradio UI and Hugging Face Spaces configuration
- retrieval evaluation dataset

## High-value next additions
1. Licensed live URL/domain reputation lookup, clearly separated from heuristics.
2. User-confirmed human-in-the-loop complaint packet before any external submission.
3. Scam-campaign clustering across repeated phone numbers, domains, wallet IDs, and message templates.
4. Elderly/low-literacy mode with larger controls and text-to-speech.
5. LangSmith evaluation dashboard for groundedness, high-risk recall, language accuracy, and latency.
